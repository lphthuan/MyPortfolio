# Thun Game Developer Portfolio

Portfolio cá nhân dành cho vị trí **Lập trình Game (Game Developer / Programmer)**.

## Hệ thống CI/CD
- Tự động đồng bộ lên iNET WordPress Hosting (WP-H1) qua **GitHub Actions** & **FTPS**.
- Nhánh triển khai: `main`.

## Công nghệ sử dụng
- **Backend & Routing**: PHP 8.x
- **Dữ liệu**: Flat-file JSON (Quản lý dự án game & đa ngôn ngữ qua Git)
- **Frontend**: Vanilla HTML5, CSS3 (Design Tokens, Glassmorphism, Theme Dark/Light), Modern JavaScript
